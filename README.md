# Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
El Chino Palma — сайт ресторана в мексиканском стиле с доставкой. Посетители знакомятся с шеф-поварами и меню с ценами, смотрят фотографии фирменных блюд и интерьера, выбирают удобное время и оставляют заявку на доставку заказа или бронирование столика.

## Практическая работа 9
Выполнена главная страница на Bootstrap-сетке.
Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ ресторана;
- сетка популярных блюд;
- подвал страницы.
